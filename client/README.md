FITbUZZ frontend

The FITbUZZ frontend is a Next.js 15 application using the App Router, React, TypeScript, and Tailwind CSS.

The main project documentation is in the repository root: [../README.md](../README.md).

## Commands

```bash
npm install
npm run dev
npm run build
npm run start
```

The frontend uses Zustand for authentication state, a typed fetch-based API service layer, and client components for workout planning, exercise tracking, nutrition logs, dashboard analytics, and calendar scheduling.
